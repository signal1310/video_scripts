# 1. Video Scripts

비디오 아카이빙을 위해 **임의 해상도(360p ~ 4K 이상) 및 코덱별 픽셀 밀도 기반 화질 분석**, **1초 키프레임 구간 이동 성능 보장**, **예상 절약 용량, 분당 절약 기반 선별**을 수행하는 Python 프레임워크입니다.

## 1.1. 첫 세팅 및 사용
- **의존성 설치** *(외부 `ffmpeg`/`ffprobe` 실행 파일이 시스템 `PATH`에 등록되어 있어야 합니다)*:
  - GUI / CUI 기본 실행: `pip install -r requirements.txt`
  - Jupyter 노트북 실행 포함: `pip install -r requirements-notebook.txt`
  - 개발, 정적 검증 도구 포함: `pip install -r requirements-dev.txt`
- 첫 실행 시 실행 폴더에 `data/rootdir.txt`, `data/config.json`, `classify.ipynb`가 기본값으로 자동 생성됩니다 (값 변경 시 재시작 없이 반영)
- 영상 분석 결과는 `data/video_cache.sqlite3`에 저장되어 재실행 후에도 재사용됩니다. 이름을 바꾼 파일도 내용이 같으면 재사용하며, 파일 메뉴의 `분석 캐시 비우기`로 모두 삭제할 수 있습니다
- **데스크톱 GUI 실행**: `python -m src` (또는 `python -m src.gui`, `python -m src --gui`)를 실행하여 대시보드, 필터링 테이블, 모의 분류 및 실제 이동/복원 기능을 사용할 수 있습니다.
- **스탠드얼론 CLI 실행**: `python -m src.cui` (또는 `python -m src --cli` 및 CLI 옵션 지정, 예: `python -m src.cui --dry-run -u gb -s saved -l 20`)로 터미널에서 분석, 모의 분류, 분류 이동/복원을 바로 실행할 수 있습니다 (`-u`/`--unit`으로 `mb`, `gb` 헤더 단위 숫자만 표기 또는 `auto` 셀별 단위 표기 전환 가능).
- **주피터 노트북(CUI) 모드 실행**: 첫 실행 시 자동 생성되는 `classify.ipynb`에서 셀을 실행하여 분석, 모의 분류(`pseudo_classify_mode`) 및 실제 폴더 이동을 수행할 수 있습니다.

# 3. 퀄리티(CQ) 기반 통합 분류 기준 및 폴더 설명

원본 해상도와 화면 비율을 100% 그대로 유지하며, 영상은 해상도, FPS, 코덱별 최적 비트레이트($B_{\text{opt}}$)를 기준으로 두 가지 비율로 판정됩니다:
- **원본 코덱 기준 비율** ($r_{\text{src}} = B_{\text{curr}} / B_{\text{opt}}$, 원본 코덱): 저화질 판정에 사용
- **출력 코덱 기준 비율** ($r_{\text{out}} = B_{\text{curr}} / B_{\text{opt}}$, 설정한 목표 인코딩 코덱): 과화질 판정과 예상 용량에 사용

판정 순서는 예외 규칙, HDR 보존, 최대 해상도 축소 재인코딩(`max_resolution_tier`가 `none`이 아닐 때, 비트레이트 맞춤 축소(`auto_downscale_by_bitrate`)가 켜져 있으면 더 낮은 규격 적용), 구형 코덱 호환 옵션(`force_legacy_compat`), 인트라 전용 코덱(`C_src >= 2.0`), 저화질(원본 기준), 과화질(출력 기준, 고성능 코덱 `+0.15` 및 비-HDR 10-bit `+0.10` 여유 포함), 적정(코덱 전환 `C_src/C_target >= 1.25` 포함, 기본 가중치에서는 H.264 원본도 해당하며 의도된 동작, 절약 기준 미달 시 `전환 절약 미달`로 보존) 순입니다. 예상 용량은 PCM 오디오 역산 차감(`pcm_*`)을 포함한 고정 용량을 유지하고, 영상 스트림에만 코덱 전환/역전 계수와 FPS, 정적 화면 가중치가 반영된 키프레임 증가율을 적용합니다.

1. **`_1_표준인코딩_CQ22`**:
   - **과화질 영상 ($r_{\text{out}} > \text{유효 상한}$, 원본 기준 저화질이 아님)**: 원본 해상도와 화면 비율을 보존하면서 `CQ 22`(화질 기준값 22) `+ 1초 키프레임`으로 재인코딩하여 눈에 띄는 화질 손실 없이 용량을 대폭 절약합니다. 720p 기준 목표 코덱 HEVC 출력이면 `1,440 kbps` 초과가 해당합니다.
   - **코덱 전환 / 구형 코덱 호환 / 적정 + 키프레임 간격 초과($> 2.2$초)**: 화질을 깎지 않고 `CQ 22 + 1초 키프레임`으로 재인코딩합니다.
2. **`_2_저화질_키프레임교정`**:
   - **저화질($r_{\text{src}} < 0.80$) + 키프레임 간격 초과($> 2.2$초)**, 또는 **블록 노이즈 위험 구형 코덱($C_{\text{src}} \ge 1.30, r_{\text{src}} < 0.90$), 코덱 역전($C_{\text{src}} < C_{\text{target}}, r_{\text{out}} < 1.0$), 초저비트레이트 정적 화면($r_{\text{src}} < 0.35$)**: 노이즈 재현과 용량 폭증을 막는 `CQ 26 + 1초 키프레임`으로 재인코딩합니다.
3. **`_3_해상도축소_` + 규격 키(예: `_3_해상도축소_720p`)** (최대 해상도 설정 시에만 대상):
   - 원본 규격이 최대 해상도를 넘고 줄였을 때 화소 수가 원본의 95% 이하인 영상을 규격 박스에 맞춰 줄여 `CQ 22 + 최대 비트레이트 + 1초 키프레임`으로 재인코딩합니다. 최대 비트레이트를 넘는 움직임 장면은 화질이 다소 낮아질 수 있습니다.
   - 줄인 상태에서도 저화질, 블록 노이즈, 코덱 역전, 정적 화면에 해당하면 축소하지 않고 원래 해상도 기준으로 판정합니다.
4. **분류되지 않고 작업 폴더에 남는 영상 (원본 보존 / 소장 확정)**:
   - 키프레임이 정상($\le 2.2$초)이면서 적정(코덱 전환 미해당) 또는 저화질인 영상
   - HDR(PQ, HLG, Dolby Vision) 영상: 색 정보를 보호하기 위해 화질 등급과 무관하게 보존
   - 절약 선별(예상 절약 용량 $< 5.0\text{ MB}$ 또는 선택한 절약 선별 기준의 분당 절약 미만)을 통과하지 못한 영상(구형 코덱 호환 옵션 및 키프레임 간격 초과 제외). 기본값인 재생 시간 기준은 대용량 절약 예외($50.0\text{ MB}$ 이상)를 허용하며, 예상 인코딩 시간 기준은 예외를 두지 않습니다.

# 4. 샤나인코더(ShanaEncoder) 프리셋 연계 (`shana_presets/`)

분류 완료 후 샤나인코더의 프리셋 폴더에 복사하여 대상 폴더별로 1:1 일괄 재인코딩을 수행할 수 있습니다.
분류 폴더 안의 모든 영상은 그 폴더에 대응하는 프리셋 하나로 재인코딩되므로, 판정 사유가 달라도 같은 폴더에 함께 배치됩니다.
모든 프리셋은 **원본 해상도 및 화면 비율을 100% 보존**하며, **1초 키프레임 구간 이동 성능 확보** 및 **오디오 무손실 복사(`-c:a copy`)**가 기본 적용되어 있습니다:

- **`_1_표준인코딩_CQ22 (NVENC).xml` / `(CPU_x265).xml`**:
  - `_1_표준인코딩_CQ22` 폴더의 영상들을 일괄 재인코딩할 때 선택합니다.
  - 고화질 유지(`CQ 22`) 및 1초 키프레임을 적용합니다.
- **`_2_저화질_키프레임교정 (NVENC).xml` / `(CPU_x265).xml`**:
  - `_2_저화질_키프레임교정` 폴더의 영상들을 일괄 재인코딩할 때 선택합니다.
  - 저화질 영상의 압축 노이즈로 인한 가짜 용량 뻥튀기를 방지(`CQ 26`)하면서 1초 키프레임만 재인코딩합니다.

# 5. 데스크톱 GUI 사용 가이드

1. **폴더 선택 및 분석 (`HeaderBar`)**
   - 상단의 작업 폴더 선택 버튼으로 폴더를 고르거나, 폴더 이름을 클릭해 경로를 직접 입력하거나, **폴더 드래그 앤 드롭**으로 작업 폴더를 지정합니다. (지원 확장자: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.wmv`, `.flv`, `.ts`, `.m2ts`, `.mts`, `.m4v`, `.3gp`, `.mpg`, `.mpeg`, `.ogv`, `.vob`, `.asf`, `.rmvb`, `.divx`)
   - 분석 분할 버튼에서 **빠른 분석**(해상도, 비트레이트 고속 조회) 또는 **정밀 분석**(키프레임 간격 실측 포함)을 선택해 실행합니다.
   - 진행 중에는 **분석 중단** 버튼 또는 `Esc` 키로 실행 중인 `ffprobe` 작업을 즉시 중단할 수 있습니다.
2. **인메모리 실시간 튜닝 및 필터링 (`FilterTuningBar`, `CriteriaTunerPanel`, `ExceptionRulesDialog`)**
   - `Ctrl+T` 단축키로 환경 설정 창(`SettingsDialog`)의 **판별 기준** 탭을 열어 화질 기준(`과화질 상한 배수`, `저화질 하한 배수`, `키프레임 간격 상한`)과 절약 기준(`최소 총 절약량`, `분당 최소 절약량`, `대용량 절약 예외 허용`)을 슬라이더로 조정하면 `ffprobe` 재실행 없이 대시보드(`BentoDashboard` 4개 핵심 지표 카드)와 테이블을 즉시 재평가합니다.
   - `예외 규칙` 버튼(`Ctrl+Shift+E`)으로 여러 줄 예외 규칙 편집기를 열어 규칙 추가, 수정, 순서 변경, 개별 활성/비활성 체크 토글을 할 수 있으며, 비활성 규칙도 `data/config.json`에 보존됩니다.
   - 파일명, 코덱 검색어와 각 열 헤더의 동적 필터 팝오버를 조합해 결과를 좁혀볼 수 있습니다.
3. **테이블 조작 및 우클릭, 메뉴바 액션 (`VideoTableView`, `MainMenuController`)**
   - 상단 메뉴바(`파일`, `편집`, `보기`, `분석`, `분류`, `도움말`)에서 최근 작업 폴더 전환, 비우기, 테마 즉시 전환, 열 표시/숨김 및 기본 정렬 복원, 기본 분석 모드 전환, 강제 재분석, 선택 행 일괄 액션, 사용 가이드, 판정 원리 탭 및 샤나인코더 프리셋 폴더 열기를 제공합니다.
   - 행 **더블클릭** 또는 `Enter` 키로 기본 미디어 플레이어에서 선택 영상을 바로 재생할 수 있습니다.
   - 선택한 영상은 `Space`로 **미리 볼 수 있습니다**. `분류` 메뉴의 `미리 보기 방식` 또는 환경 설정의 `미리 보기 방식`에서 `내장 미리 보기`(앱 안의 창에서 재생, 재생과 일시중지, 재생 위치 막대, 볼륨 조절, 좌우 방향키로 구간 이동(간격은 환경 설정의 `구간 이동 간격`), 위아래 방향키로 표에서 이전, 다음 영상 이동, 미리 보기 중 표에서 다른 영상을 클릭하면 그 영상으로 교체, 여러 개를 선택한 상태의 `Space`는 가장 위 영상만 미리 봄)와 `QuickLook`(설치된 QuickLook에 넘김, 미설치 시 안내) 중 고를 수 있습니다.
  - 행 우클릭 및 `분류` 메뉴에서 **다중 선택 영상 재생**, 탐색기에서 위치 열기, 파일명 복사, **전체 경로 복사**, **선택 항목 예외 규칙 추가/제거**를 지원합니다.
   - 행 우클릭 및 `분류` 메뉴의 **출력 해상도 지정** 하위 메뉴에서 선택 영상의 출력 해상도를 `자동`, `축소 안 함`, 규격(4K부터 360p)으로 고를 수 있습니다. 선택은 재분석 없이 즉시 재평가되어 저장되고, `분류` 메뉴의 `직접 지정 모두 해제`로 현재 작업 폴더의 지정을 확인 후 한꺼번에 풀 수 있습니다. 예외 규칙, HDR 영상과 축소 효과가 없는 규격은 비활성화됩니다. 키보드로는 `Ctrl+R`로 지정 메뉴를 열거나, `Ctrl+1`~`Ctrl+8`(360p부터 4K까지 규격 순서), `Ctrl+0`(자동), `Ctrl+9`(축소 안 함)로 바로 지정합니다.
   - 열 헤더의 **필터 아이콘** 또는 **헤더 우클릭 메뉴**에서 열별 데이터 타입(열거형, 범주형 다중 체크, 수치 범위, 미측정, 문자열 조건)에 맞는 동적 필터 팝오버를 열어 즉시 필터링하고, 컬럼 표시/숨김 및 기본 열 너비 복원을 할 수 있습니다. 창 크기, 컬럼 배치는 자동 저장됩니다.
4. **환경 설정, 실제 이동 및 복원 (`SettingsDialog`, `FooterBar`)**
   - `환경 설정` 탭(`Ctrl+,`)에서는 테마(시스템 적응형 / 다크 / 라이트), 작업 폴더, 분류 폴더명, 목표 인코딩 방식(HEVC NVENC / CPU x265 / H.264 / AV1 등), 구형 코덱 호환 재인코딩, 기준 배속(CPU, GPU, FFmpeg 인코더 기반 `시스템 자동 감지` 지원) 및 `data/config.json`에 저장되는 36개 세부 기준값(실시간 조정 6종은 같은 창의 `Ctrl+T` `판별 기준` 탭에 배치)을 UI에서 직접 검증, 저장할 수 있습니다.
   - **분류 폴더로 이동** 실행 시 기존 대상 파일과 이름이 충돌하면 덮어쓰지 않고 건너뛰며, 중간 I/O 오류 시 이전 이동 파일을 작업 폴더로 자동 롤백합니다. **작업 폴더로 복원**은 분류 폴더의 파일을 작업 폴더로 복구하고 빈 폴더를 정리합니다.
5. **되돌리기와 다시 실행 (`Ctrl+Z`, `Ctrl+Y` / `Ctrl+Shift+Z`)**
   - 출력 해상도 지정, 예외 규칙, 판별 기준, 환경 설정, 단축키 변경, 전체 초기화, 열 너비, 열 표시, 열 순서 변경을 최대 50단계까지 되돌리고 다시 적용합니다. 전체 초기화를 되돌리면 단축키, 테마, 분석 모드, 검색어도 함께 복구됩니다.
   - 판별 기준 슬라이더처럼 연속으로 조정한 값은 800ms 안에 이어지면 한 단계로 묶습니다. 되돌린 뒤 새 변경을 하면 다시 실행 기록은 지워집니다.
   - 분류 이동과 작업 폴더 복원, 정렬, 상단 영역 접기는 되돌리기 대상이 아닙니다.
6. **단축키 설정 (`Ctrl+K`)**
   - 환경 설정 창의 `단축키` 탭에서 명령마다 단축키를 지정, 해제하거나 기본값으로 되돌릴 수 있습니다.
   - 다른 명령과 겹치는 키를 지정하면 확인 후 기존 명령의 단축키를 해제합니다. 변경 내용은 즉시 저장되며 메뉴 항목, 버튼 툴팁, 사용 가이드에 반영됩니다.

# 6. 예외 규칙 문법 (키워드, AST 안전 조건식)

GUI의 **예외 규칙** 편집기(`Ctrl+Shift+E`)에서는 쉼표(`,`) 또는 세미콜론(`;`)으로 구분해 여러 규칙을 한 번에 추가하거나 개별 행 단위로 관리할 수 있습니다. 일치하는 영상은 화질, 키프레임 판정과 무관하게 재인코딩에서 제외되어 원본 보존 처리됩니다.

1. **파일명 키워드**: 일반 문자열을 입력하면 대소문자 구분 없이 `v.filename` 부분 일치로 검사합니다.
   - 예: `sample, 무손실, keep_origin`
2. **안전 조건식 (`v.*` 또는 `lambda v: ...`)**: `eval()`/`compile()`을 쓰지 않고 화이트리스트 기반 AST 해석기로 평가합니다.
   - 예: `v.duration < 10, v.fps >= 60`
   - 예: `v.codec == 'hevc' and v.width >= 3840`
   - 예: `lambda v: v.vid_size_MB < 50 or v.filename.startswith('raw_')`
   - **사용 가능한 `VideoProps` 속성 (`v.*`)**: `filename`, `width`, `height`, `rotate_type`, `fps`, `vid_kbps`, `aud_kbps`, `vid_size_MB`, `duration`, `codec`, `keyframe_interval`, `moved_dirname`, `aspect_ratio`
   - **허용 함수, 메서드**: 내장 함수 `abs`, `min`, `max`, `round`, `len` / 문자열 메서드 `lower`, `upper`, `strip`, `lstrip`, `rstrip`, `startswith`, `endswith`, `isdigit`, `isnumeric`

*(노트북/Python API에서는 `classifier.add_exception_rule(lambda v: ...)`로 일반 Python 조건 함수를 등록할 수 있습니다.)*
