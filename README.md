# 1. Video Scripts

비디오 아카이빙을 위해 **임의 해상도(360p ~ 4K 이상) 및 코덱별 픽셀 밀도 기반 화질 분석**, **1초 키프레임 구간 이동 성능 보장**, **예상 절약 용량, 분당 절약 기반 선별**을 수행하는 Python 프레임워크입니다.

## 1.1. 첫 세팅 및 사용
- **의존성 설치** *(외부 `ffmpeg`/`ffprobe` 실행 파일이 시스템 `PATH`에 등록되어 있어야 합니다)*:
  - GUI / CUI 기본 실행: `pip install -r requirements.txt`
  - Jupyter 노트북 실행 포함: `pip install -r requirements-notebook.txt`
  - 개발, 정적 검증 도구 포함: `pip install -r requirements-dev.txt`
- 첫 실행 시 실행 폴더에 `data/rootdir.txt`, `data/config.json`, `classify.ipynb`가 기본값으로 자동 생성됩니다 (값 변경 시 재시작 없이 반영)
- 영상 분석 결과는 `data/video_cache.sqlite3`에 저장되어 재실행 후에도 재사용됩니다. 이름을 바꾼 파일도 내용이 같으면 재사용하며, 파일 메뉴의 `분석 캐시 비우기`로 모두 삭제할 수 있습니다
- **데스크톱 GUI 실행**: `python -m src` (또는 `python -m src.gui`, `python -m src --gui`)를 실행하여 대시보드, 필터링 테이블, 분석 결과와 재인코딩 판정을 표로 확인할 수 있습니다.
- **스탠드얼론 CLI 실행**: `python -m src.cui` (또는 `python -m src --cli` 및 CLI 옵션 지정, 예: `python -m src.cui -u gb -s saved -l 20`)로 터미널에서 분석과 판정 결과를 바로 출력할 수 있습니다 (`-u`/`--unit`으로 `mb`, `gb` 헤더 단위 숫자만 표기 또는 `auto` 셀별 단위 표기 전환 가능).
- **주피터 노트북(CUI) 모드 실행**: 첫 실행 시 자동 생성되는 `classify.ipynb`에서 셀을 실행하여 영상 분석과 판정 결과 출력을 수행할 수 있습니다.

# 3. 화질 기준값 기반 판정 기준과 권장 처리

원본 해상도와 화면 비율을 100% 그대로 유지하며, 영상은 해상도, FPS, 코덱별 최적 비트레이트($B_{\text{opt}}$)를 기준으로 두 가지 비율로 판정됩니다:
- **원본 코덱 기준 비율** ($r_{\text{src}} = B_{\text{curr}} / B_{\text{opt}}$, 원본 코덱): 저화질 판정에 사용
- **출력 코덱 기준 비율** ($r_{\text{out}} = B_{\text{curr}} / B_{\text{opt}}$, 설정한 목표 인코딩 코덱): 과화질 판정과 예상 용량에 사용

판정 순서는 예외 규칙, HDR 보존, 최대 해상도 축소 재인코딩(`max_resolution_tier`가 `none`이 아닐 때, 비트레이트 맞춤 축소(`auto_downscale_by_bitrate`)가 켜져 있으면 더 낮은 규격 적용), 구형 코덱 호환 옵션(`force_legacy_compat`), 인트라 전용 코덱(`C_src >= 2.0`), 저화질(원본 기준), 과화질(출력 기준, 고성능 코덱 `+0.15` 및 비-HDR 10-bit `+0.10` 여유 포함), 적정(코덱 전환 `C_src/C_target >= 1.25` 포함, 기본 가중치에서는 H.264 원본도 해당하며 의도된 동작, 절약 기준 미달 시 `전환 절약 미달`로 보존) 순입니다. 예상 용량은 PCM 오디오 역산 차감(`pcm_*`)을 포함한 고정 용량을 유지하고, 영상 스트림에만 코덱 전환/역전 계수와 FPS, 정적 화면 가중치가 반영된 키프레임 증가율을 적용합니다.

1. **`품질 22 재인코딩`**:
   - **과화질 영상 ($r_{\text{out}} > \text{유효 상한}$, 원본 기준 저화질이 아님)**: 원본 해상도와 화면 비율을 보존하면서 `품질 22.0`(화질 기준값, 기본 22.0) `+ 1초 키프레임`으로 재인코딩하여 눈에 띄는 화질 손실 없이 용량을 대폭 절약합니다. 720p 기준 목표 코덱 HEVC 출력이면 `1,440 kbps` 초과가 해당합니다.
   - **코덱 전환 / 구형 코덱 호환 / 적정 + 키프레임 간격 초과($> 2.2$초)**: 화질을 깎지 않고 `품질 22 + 1초 키프레임`으로 재인코딩합니다.
2. **`품질 26 재인코딩`**:
   - **저화질($r_{\text{src}} < 0.80$) + 키프레임 간격 초과($> 2.2$초)**, 또는 **블록 노이즈 위험 구형 코덱($C_{\text{src}} \ge 1.30, r_{\text{src}} < 0.90$), 코덱 역전($C_{\text{src}} < C_{\text{target}}, r_{\text{out}} < 1.0$), 초저비트레이트 정적 화면($r_{\text{src}} < 0.35$)**: 노이즈 재현과 용량 폭증을 막는 `품질 26 + 1초 키프레임`으로 재인코딩합니다.
3. **축소 재인코딩** (최대 해상도 설정 시에만 대상, 규격 키 예: `720p`):
   - 원본 규격이 최대 해상도를 넘고 줄였을 때 화소 수가 원본의 95% 이하인 영상을 규격 박스에 맞춰 줄여 `품질 22 + 최대 비트레이트 + 1초 키프레임`으로 재인코딩합니다. 최대 비트레이트를 넘는 움직임 장면은 화질이 다소 낮아질 수 있습니다.
   - 줄인 상태에서도 저화질, 블록 노이즈, 코덱 역전, 정적 화면에 해당하면 축소하지 않고 원래 해상도 기준으로 판정합니다.
4. **원본 보존 (재인코딩 대상 아님)**:
   - 키프레임이 정상($\le 2.2$초)이면서 적정(코덱 전환 미해당) 또는 저화질인 영상
   - HDR(PQ, HLG, Dolby Vision) 영상: 색 정보를 보호하기 위해 화질 등급과 무관하게 보존
   - 이미 재인코딩된 영상(결과 파일에 기록된 재인코딩 표식이 있음): 다시 인코딩하면 화질이 한 번 더 떨어지므로 보존. 출력 해상도를 직접 지정하면 그 값으로 다시 판정
   - 절약 선별(예상 절약 용량 $< 5.0\text{ MB}$ 또는 선택한 절약 선별 기준의 분당 절약 미만)을 통과하지 못한 영상(구형 코덱 호환 옵션 및 키프레임 간격 초과 제외). 기본값인 재생 시간 기준은 대용량 절약 예외($50.0\text{ MB}$ 이상)를 허용하며, 예상 인코딩 시간 기준은 예외를 두지 않습니다.

# 4. 데스크톱 GUI 사용 가이드

1. **폴더 선택 및 분석 (`HeaderBar`)**
   - 상단의 작업 폴더 선택 버튼으로 폴더를 고르거나, 폴더 이름을 클릭해 경로를 직접 입력하거나, **폴더 드래그 앤 드롭**으로 작업 폴더를 지정합니다. (지원 확장자: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.wmv`, `.flv`, `.ts`, `.m2ts`, `.mts`, `.m4v`, `.3gp`, `.mpg`, `.mpeg`, `.ogv`, `.vob`, `.asf`, `.rmvb`, `.divx`)
   - 분석 분할 버튼에서 **빠른 분석**(해상도, 비트레이트 고속 조회) 또는 **정밀 분석**(키프레임 간격 실측 포함)을 선택해 실행합니다.
   - 진행 중에는 **분석 중단** 버튼 또는 `Esc` 키로 실행 중인 `ffprobe` 작업을 즉시 중단할 수 있습니다.
   - 분석 메뉴의 **선택 영상 화질 분석**, **전체 영상 화질 분석**은 검은 띠를 뺀 활성 화면과 규격별 축소 후보를 측정합니다. 하단 상태 줄에는 `검은 여백 확인`, `축소 후보 선별 (k/N)`, `VMAF 정밀 확인 (k/N)` 세부 단계와 예상 남은 시간이 표시되고, 진행 막대 툴팁에서 임시 작업 폴더를 확인할 수 있습니다. 환경 설정의 `화질 분석 방식`에서 `빠름`(0.5초), `균형`(1초, 기본), `정밀`(2초)을 고를 수 있으며 방식을 바꾸면 다음 분석에서 기존 캐시를 쓰지 않고 새 방식으로 다시 잽니다. 결과 1건 이상이면 표의 `활성 화면`, `축소 후보` 열이 자동으로 표시되고, `측정 지표` 열은 `보기 > 표시할 열`에서 켭니다.
2. **인메모리 실시간 튜닝 및 필터링 (`FilterTuningBar`, `CriteriaTunerPanel`, `ExceptionRulesDialog`)**
   - `Ctrl+T` 단축키로 환경 설정 창(`SettingsDialog`)의 **판별 기준** 탭을 열어 화질 기준(`과화질 상한 배수`, `저화질 하한 배수`, `키프레임 간격 상한`)과 절약 기준(`최소 총 절약량`, `분당 최소 절약량`, `대용량 절약 예외 허용`)을 슬라이더로 조정하면 `ffprobe` 재실행 없이 대시보드(`BentoDashboard` 4개 핵심 지표 카드)와 테이블을 즉시 재평가합니다.
   - `예외 규칙` 버튼(`Ctrl+Shift+E`)으로 여러 줄 예외 규칙 편집기를 열어 규칙 추가, 수정, 순서 변경, 개별 활성/비활성 체크 토글을 할 수 있으며, 비활성 규칙도 `data/config.json`에 보존됩니다.
   - 파일명, 코덱 검색어와 각 열 헤더의 동적 필터 팝오버를 조합해 결과를 좁혀볼 수 있습니다.
3. **테이블 조작 및 우클릭, 메뉴바 액션 (`VideoTableView`, `MainMenuController`)**
   - 상단 메뉴바(`파일`, `편집`, `보기`, `분석`, `재인코딩`, `도움말`)에서 최근 작업 폴더 전환, 비우기, 테마 즉시 전환, 열 표시/숨김 및 기본 정렬 복원, 기본 분석 모드 전환, 강제 재분석, 선택 행 일괄 액션, 사용 가이드, 판정 원리 탭을 제공합니다.
   - 행 **더블클릭** 또는 `Enter` 키로 기본 미디어 플레이어에서 선택 영상을 바로 재생할 수 있습니다.
   - 선택한 영상은 `Space`로 **내장 미리 보기 창에서 볼 수 있습니다**. 구간 이동 간격과 정보 표시 설정은 `편집` 메뉴의 `미리 보기 설정...` 또는 내장 미리 보기 창의 설정 버튼에서 바꿉니다(단축키만 `단축키 설정`에서 지정). `내장 미리 보기`는 앱 안의 창에서 재생하며, 재생과 일시중지, 재생 위치 막대, 볼륨 조절, 좌우 방향키 구간 이동(`Shift`와 함께 누르면 더 넓은 구간), `,`/`.`로 한 프레임 뒤/앞 이동, 조작 바에서 재생 배속(0.25배부터 3배까지는 0.25, 0.5배 간격, 3배 이후는 0.5배 간격으로 8배까지, 저장됨), 위아래 방향키로 표에서 이전, 다음 영상 이동, 미리 보기 중 표에서 다른 영상을 클릭하면 그 영상으로 교체(창은 다른 창 위에 떠 있음), 여러 개를 선택한 상태의 `Space`는 가장 위 영상만 미리 봅니다. `I`로 영상 위 **정보 표시**를 끔, 요약, 상세 순서로 전환합니다. 표 열과 같은 항목(코덱, 비트레이트, 화질 등급, 출력 해상도 등)은 표와 같은 값과 이름으로 보이고, 재생 해상도, 화면 크기, 재생 FPS, 프레임 시각 같은 재생기 상태도 고를 수 있습니다. 영상 위에서는 표 헤더와 같은 약어(BR, KF 간격)로 보이고 미리 보기 설정에서는 풀네임으로 고릅니다. 정보 표시는 끌어서 옮기고, 가장자리나 모서리를 끌어 정보 상자의 너비와 높이를 따로 바꿀 수 있으며(글자 크기는 그대로, 글상자처럼 줄바꿈이 상자 너비를 따름), 마우스 휠이나 설정의 `정보 크기`로 글자 크기를 바꿉니다. 표시할 항목은 미리 보기 설정에서 체크하고, 체크한 항목의 순서는 `요약 표시 순서`, `상세 표시 순서` 목록을 끌어서 바꿉니다. 위치, 상자 크기, 글자 크기는 `위치와 크기 초기화`로 한 번에 되돌립니다. 표시 항목과 순서, 한 줄/여러 줄 배치, 위치, 정보 상자 크기, 정보 크기는 다시 실행해도 유지됩니다. 전체화면에서도 `Ctrl+4` 같은 출력 해상도 지정 단축키와 `Ctrl+Z` 되돌리기가 선택한 영상 전체에 적용되며, 결과 문구가 영상 위에 잠깐 표시됩니다. 조작 바의 **화질 비교** 버튼은 지금 재생 시점 그대로 화질 비교 창으로 전환하고(미리 보기 창은 재생을 멈추고 숨김), `Ctrl+B`(`화질 비교 전환`)로도 같은 전환을 합니다. 조작 바 오른쪽 끝의 `단축키 안내` 버튼에 마우스를 올리면 지금 설정된 미리 보기 단축키를 2열 키캡 표로 보여 주며, 버튼과 팝오버 밖으로 마우스를 옮기면 닫힙니다. 화질 비교 창에서 `Ctrl+B`를 누르면 그 시점과 창 위치 그대로 미리 보기로 돌아옵니다.
  - 행 우클릭 및 `편집` 메뉴에서 **다중 선택 영상 재생**, 탐색기에서 위치 열기, 파일명 복사, **전체 경로 복사**, **선택 항목 예외 규칙 추가/제거**를 지원합니다.
   - 행 우클릭의 `선택 영상 재생` 바로 아래 **화질 비교...** 는 그 영상의 **화질 비교** 창을 엽니다. 창은 하나만 띄우고 이미 열려 있으면 새 대상으로 바꿔 앞으로 가져옵니다. 재인코딩 결과가 있으면 `결과`를, 없으면 원본에서 줄일 수 있는 `{규격} 축소 비교` 프레임을 같은 시점에서 비교합니다. `분할선`, `즉시 전환`, `좌우 비교` 세 방식과 `맞춤`, `1:1`, `200%`, `400%` 확대, 우측 상단 배율 입력 칸(`10%~800%` 직접 입력)을 지원합니다. 상단 2줄 조작 바는 캔버스 위에 도킹되고 `H` 또는 접기 버튼으로 접으면 캔버스가 위까지 넓어지며, 마우스를 캔버스 위쪽 가장자리로 옮기면 반투명 오버레이로 나타나고 마우스가 그 밖으로 벗어나면 잠깐 뒤 사라집니다(메뉴, 배율 입력, 단축키 안내를 조작하는 동안과 오버레이 위에 있는 동안은 자동으로 숨지 않음). 하단 재생 바는 한 줄로 항상 고정되고 오른쪽 끝에 전체화면 전환과 `단축키 안내` 버튼을 둡니다. 같은 창에서 재생, 일시중지, 재생 배속(`0.25배~8배`), 음소거, 볼륨을 조절할 수 있고, 이 값들은 내장 미리 보기와 함께 저장되어 창을 오가도 그대로 이어집니다. 미리 보기와 비교 창은 `Ctrl+B`로 오갈 때 현재 시점과 재생/일시중지 상태까지 이어받고, 화질 비교 창을 열 때마다 저장된 배속, 음량, 음소거를 다시 읽습니다. 시점 프레임은 영상을 열어 둔 채 꺼내는 PyAV 메모리 디코더로 읽어 1프레임 이동을 10ms 안팎으로 줄이고, 지원하지 않는 코덱이나 회전 영상은 FFmpeg로 대체합니다. 재생 중에는 비교 모드와 확대, 이동이 실시간 프레임에 그대로 적용되며, 일시중지하거나 `,`/`.`로 1프레임 이동하면 그 시점을 정확한 정지 화면으로 다시 읽습니다. 시점을 바꿔 프레임을 읽는 동안에는 기존 화면을 가리지 않고 0.25초를 넘길 때만 캔버스 위에 작은 `프레임을 불러오는 중...` 배지를 띄웁니다. 4배속 이상에서도 화면 갱신을 30fps로 제한해 조작이 끊기지 않습니다. 창 안 단축키는 `1`/`2`/`3` 모드, `C` 또는 마우스 누르기 원본/비교 전환, 좌우 방향키 구간 이동(`Shift`와 함께 누르면 6배), `,`/`.` 1프레임, `K` 재생/일시중지, `[`/`]`/`\` 재생 배속 낮추기/높이기/1배, `M` 음소거, `0` 맞춤, `+`/`-` 확대/축소, 마우스 휠 확대, `F` 전체화면 전환, `H` 조작 바 접기/펼치기, `Ctrl+B` 미리 보기 전환, `Space`/`Esc` 닫기입니다. 이 키들은 `단축키 설정`의 `화질 비교 창` 그룹에서 바꿀 수 있고, 조작 바 툴팁과 `단축키 안내` 팝오버에 즉시 반영됩니다. 재인코딩 진행 창의 완료, 교체 대기 결과 행에도 같은 아이콘 버튼이 있습니다.
   - 행 우클릭 및 `편집` 메뉴의 **출력 해상도 지정** 하위 메뉴에서 선택 영상의 출력 해상도를 `자동`, `축소 안 함`, 규격(4K부터 360p)으로 고를 수 있습니다. 같은 하위 메뉴의 `화질 분석 후보 적용`은 선택 영상마다 화질 분석에서 찾은 축소 후보 규격을 개별 적용하고, 후보가 없거나 예외 규칙, HDR 영상인 행은 건너뜁니다. 행 우클릭의 `VR 영상으로 보호`는 검은 띠 감지와 잘라내기에서만 보호하며 축소 후보는 정상 측정합니다. 선택은 재분석 없이 즉시 재평가되어 저장되고, `편집` 메뉴의 `직접 지정 모두 해제`로 현재 작업 폴더의 지정을 확인 후 한꺼번에 풀 수 있습니다. 예외 규칙, HDR 영상과 축소 효과가 없는 규격은 비활성화됩니다. 키보드로는 `Ctrl+R`로 지정 메뉴를 열거나, `Ctrl+1`~`Ctrl+8`(360p부터 4K까지 규격 순서), `Ctrl+0`(자동), `Ctrl+9`(축소 안 함)로 바로 지정합니다.
   - 열 헤더의 **필터 아이콘** 또는 **헤더 우클릭 메뉴**에서 열별 데이터 타입(열거형, 범주형 다중 체크, 수치 범위, 미측정, 문자열 조건)에 맞는 동적 필터 팝오버를 열어 즉시 필터링하고, 컬럼 표시/숨김 및 기본 열 너비 복원을 할 수 있습니다. 창 크기, 컬럼 배치는 자동 저장됩니다.
4. **환경 설정 (`SettingsDialog`)**
   - `환경 설정` 탭(`Ctrl+,`)에서는 테마(시스템 적응형 / 다크 / 라이트), 작업 폴더, 목표 인코딩 방식(HEVC NVENC / CPU x265 / H.264 / AV1 등), 구형 코덱 호환 재인코딩, 기준 배속(CPU, GPU, FFmpeg 인코더 기반 `시스템 자동 감지` 지원) 및 `data/config.json`에 저장되는 49개 세부 기준값(실시간 조정 6종은 같은 창의 `Ctrl+T` `판별 기준` 탭에 배치)을 UI에서 직접 검증, 저장할 수 있습니다.
5. **되돌리기와 다시 실행 (`Ctrl+Z`, `Ctrl+Y` / `Ctrl+Shift+Z`)**
   - 출력 해상도 지정, 예외 규칙, 판별 기준, 환경 설정, 단축키 변경, 전체 초기화, 열 너비, 열 표시, 열 순서 변경을 최대 50단계까지 되돌리고 다시 적용합니다. 전체 초기화를 되돌리면 단축키, 테마, 분석 모드, 검색어도 함께 복구됩니다.
   - 판별 기준 슬라이더처럼 연속으로 조정한 값은 800ms 안에 이어지면 한 단계로 묶습니다. 되돌린 뒤 새 변경을 하면 다시 실행 기록은 지워집니다.
6. **단축키 설정 (`Ctrl+K`)**
   - 환경 설정 창의 `단축키` 탭에서 명령마다 단축키를 지정, 해제하거나 기본값으로 되돌릴 수 있습니다.
   - 다른 명령과 겹치는 키를 지정하면 확인 후 기존 명령의 단축키를 해제합니다. 변경 내용은 즉시 저장되며 메뉴 항목, 버튼 툴팁, 사용 가이드에 반영됩니다.

재인코딩은 `재인코딩` 메뉴의 `재인코딩 시작...`(`Ctrl+G`)으로 시작 확인 창을 연 뒤에만 실행합니다. 중단되었거나 이어 하지 않은 배치가 남긴 임시 파일은 `재인코딩` 메뉴의 `임시 파일 정리...`에서 골라 휴지통으로 옮길 수 있으며, 원본 영상은 바뀌지 않습니다. 이전 재인코딩에서 결과가 원본보다 커서 폐기된 기록은 `재인코딩` 메뉴의 `이전 폐기 기록 비우기...`로 비워 다시 대상에 넣을 수 있습니다. 확인 창에서 영향을 집계로 보고, 영상 행은 더블클릭으로 재생하고 `Space`로 미리 볼 수 있으며, 확인 창이 열려 있는 동안 미리 보기 창은 확인 창에서 고른 영상을 보여 줍니다. 결과 파일에는 재인코딩 태그(탐색기 태그 키워드와 상세 값, 설정에서 기록 방식을 고름)를 남기고, 태그, 상세 값, 재인코딩 이력 가운데 하나라도 일치하는 영상은 다시 인코딩 대상에 넣지 않습니다(결정 28).

# 6. 예외 규칙 문법 (키워드, AST 안전 조건식)

GUI의 **예외 규칙** 편집기(`Ctrl+Shift+E`)에서는 쉼표(`,`) 또는 세미콜론(`;`)으로 구분해 여러 규칙을 한 번에 추가하거나 개별 행 단위로 관리할 수 있습니다. 일치하는 영상은 화질, 키프레임 판정과 무관하게 재인코딩에서 제외되어 원본 보존 처리됩니다.

1. **파일명 키워드**: 일반 문자열을 입력하면 대소문자 구분 없이 `v.filename` 부분 일치로 검사합니다.
   - 예: `sample, 무손실, keep_origin`
2. **안전 조건식 (`v.*` 또는 `lambda v: ...`)**: `eval()`/`compile()`을 쓰지 않고 화이트리스트 기반 AST 해석기로 평가합니다.
   - 예: `v.duration < 10, v.fps >= 60`
   - 예: `v.codec == 'hevc' and v.width >= 3840`
   - 예: `lambda v: v.vid_size_MB < 50 or v.filename.startswith('raw_')`
   - **사용 가능한 `VideoProps` 속성 (`v.*`)**: `filename`, `width`, `height`, `rotate_type`, `fps`, `vid_kbps`, `aud_kbps`, `vid_size_MB`, `duration`, `codec`, `keyframe_interval`, `aspect_ratio`
   - **허용 함수, 메서드**: 내장 함수 `abs`, `min`, `max`, `round`, `len` / 문자열 메서드 `lower`, `upper`, `strip`, `lstrip`, `rstrip`, `startswith`, `endswith`, `isdigit`, `isnumeric`

*(노트북/Python API에서는 `classifier.add_exception_rule(lambda v: ...)`로 일반 Python 조건 함수를 등록할 수 있습니다.)*
